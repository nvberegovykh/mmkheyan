Content Items

Uploads are automatically resized, get a subtle low-opacity signature tiled across the image, and have a one-way cryptographic (HMAC) signature embedded invisibly in the pixel data — proof of authenticity that only this admin panel can create. The original file you choose is never uploaded or stored anywhere; only this processed copy leaves your browser.

Site Settings

Batch Upload

Select several images at once. Each one is resized, gets the tiled visible signature, and has the cryptographic signature embedded and uploaded automatically, one after another — no need to click or wait between files. As each finishes it appears in Content Items above; click "Edit" on it whenever you're ready to fill in name, size, material, etc.

    Verify Authenticity

    Check whether an image file or URL carries a genuine, unaltered cryptographic signature from this admin panel. This is a hard yes/no check backed by a secret key that never leaves the server — it cannot be spoofed by editing the image or its metadata.
